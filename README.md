# Gwajimanization

Website ya kanisa iliyotengenezwa kwa HTML, CSS na JavaScript na iko tayari kwa GitHub Pages.

## Kuweka kwenye GitHub Pages

1. Fungua GitHub na tengeneza repository mpya, kwa mfano `gwajimanization`.
2. Upload `index.html`, `style.css`, `script.js` na folder `audio`.
3. Nenda **Settings → Pages**.
4. Chagua **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`, kisha Save.
6. GitHub itakupa link ya website.

## Kuweka mahubiri mapya

Weka MP3 ndani ya folder `audio/`, mfano:
`audio/mahubiri-4.mp3`

Kisha ongeza card nyingine kwenye `index.html` yenye:
`<source src="audio/mahubiri-4.mp3" type="audio/mpeg">`

## Muhimu kabla ya kuchapisha

Badilisha namba za sadaka, taarifa za benki, simu, WhatsApp na email za mfano zilizopo kwenye `index.html` ziwe taarifa rasmi za kanisa.
